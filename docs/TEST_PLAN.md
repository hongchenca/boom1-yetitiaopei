# 测试与证据计划

## 测试层级

| 层级 | 内容 | 证据 |
| --- | --- | --- |
| 主机纯逻辑 | 单位换算、范围校验、滤波/稳定窗口、预测停泵、点动、状态转移、错误码 | 可重复单元测试、边界与属性样例 |
| 驱动台架 | HX711 采样时序/断线、PCA9685 初始化/频率/回读/I2C 恢复、全关断 | 逻辑分析仪、寄存器回读与负载端独立测量、故障注入日志 |
| 计量台架 | 已知砝码/液体、空容器、不同流量、尾流、滴液、振动和温漂 | 原始称重数据、校准版本、误差预算 |
| 控制集成 | 每个状态、取消、超时、传感器失效、中央秤交叉验证、任务恢复 | 状态事件时间线、泵/气路波形 |
| 电气安全 | 复位/上电/掉电/看门狗/I2C 卡死/功率级故障/急停 | 负载端示波器/电流、关断响应时间 |
| 系统/网络 | 本机启动、局域网跨终端访问、HTTP/SSE、设备主动上报、25 秒长轮询、离线自动执行、重连、重复/迟到命令、鉴权、配置原子更新、OTA 回滚 | 浏览器检查、协议抓包、设备日志、版本/hash |
| 长稳/制造 | 长时间循环、泄漏/过热/EMC、线束误插、校准与出厂流程 | 测试报告、序列号和硬件版本可追溯 |

## 必测场景

1. 九路任一路未连接、数据冻结、超量程、噪声超限、校准版本不匹配。
2. PCA9685 NACK、错误地址、输出回读不一致、OE/硬件使能异常、单路 MOSFET 故障。
3. 快加到精加的边界、预测值缺失/越界、停泵尾流、稳定超时、点动达到上限、过量。
4. 中央秤不稳定、`sum(source_loss)` 与 `main_gain` 超出各级质量带、管路残液和滴液延迟。
5. 电源复位、看门狗、OTA 中断、网络掉线、事件队列满、NVS 掉电写入。
6. 重复提交/取消、乱序/过期命令、未授权校准、配置越界和保留 PWM 通道引用。
7. 调试会话续期中断、浏览器关闭、电脑休眠、后台重启和设备重启：调试输出按租约停止，自动任务按本地状态机继续；停止回执和最终记录可追溯。
8. 参数草稿、显式保存、下一任务生效、配置版本冲突、设备实际回执值与页面显示一致；HTTP 接受不能被误显示为执行完成。
9. 交付包在干净目录使用根路径和子路径启动，验证独立数据目录、SQLite 在线/停服备份恢复、升级回滚和不触碰其他资料。

## 验证记录要求

每次记录仓库版本/脏状态、构建 profile、ESP-IDF/编译器版本、sdkconfig/分区、ELF/bin/hash、板卡和探针 ID、命令与输入、时间戳、日志/波形路径、结论。结论只能写 `[PASS]`、`[FAIL]`、`[NOT RUN]`、`[HW REQUIRED]` 或 `[ASSUMPTION]`。编译通过仅证明编译，不能代替上电、关断或计量验收。

## 时序预算

Phase 1 建立采样周期、最坏 I2C 事务、控制周期、关断响应、稳定时间、队列积压和看门狗余量的预算表；没有预算的状态超时与任务节拍不得写成硬编码常数。
