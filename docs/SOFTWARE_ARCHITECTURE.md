# 软件架构与接口契约

## 计划目录和依赖

当前目录只有 `main/` 示例；以下是后续实施的目标结构，不表示文件已存在。

```text
main/                      启动、依赖装配与安全初始化
components/domain/         类型、配置校验、配方与质量运算，无硬件依赖
components/weight/         HX711 驱动、九路采集、校准和稳定窗口
components/actuator/       PCA9685、硬件关断与输出仲裁
components/dosing/         单任务状态机与剂量控制
components/safety/         故障汇聚、互锁、急停与安全停机
components/command/        命令校验、去重和任务队列
components/storage/        配置、标定、任务结果持久化
components/connectivity/   可选 MQTT/HTTP/OTA 适配
tests/                     主机侧纯逻辑测试及硬件台架测试
docs/                      设计、ADR、任务和验收记录
```

依赖方向：`domain` 不依赖其他项目组件；`weight`、`actuator`、`storage` 依赖 `domain` 与 ESP-IDF；`dosing` 依赖 `domain` 及 `weight`/`actuator` 的窄接口；`safety` 观察服务健康并拥有关断请求权；`command` 依赖 `domain` 与 `dosing` 命令入口；`connectivity` 只依赖 `command` 和只读状态/事件接口。禁止反向依赖、全局可写状态或跨组件直接调用底层 GPIO/I2C。

## 公共数据与服务契约（语义版，C 签名在 Phase 1 冻结）

| 契约 | 输入/输出 | 关键规则 |
| --- | --- | --- |
| `WeightSnapshot` | `scale_id` 0~8、原始值、校准质量 mg、单调时间 ms、校准版本、有效/稳定/故障标志 | 质量使用有符号 64 位整数 mg；采样旧于配置上限或校准失效时不得用于控制 |
| `WeightService.read_snapshot` | 通道 ID -> 最新快照/错误 | 有界执行，不等待下一次转换；九路时间戳不得假定同时 |
| `DoseRecipe` | recipe_id/version、各通道目标 mg、容差 mg、步骤顺序 | 目标和容差需有正值/上下限检查；输入数据与执行快照分离 |
| `DosingCommand.submit/cancel` | 命令 ID、来源、配方/取消目标 -> 接受/拒绝及原因 | 仅接受校验后的命令；重复 ID 幂等，取消可抢占排队命令 |
| `DosingStatus.snapshot` | 任务 ID、步骤、状态、累计质量、故障、时间戳 | 返回一致的只读快照；网络不得持有内部可变对象指针 |
| `Actuator.set/stop_all` | 授权令牌、通道、0~100% 目标占空比/全关 -> 结果 | 只有控制器/安全路径可调用；频率为全局配置，失败关断并锁存 |
| `Safety.trip/clear` | 故障代码/复核凭据 -> 锁存/清除结果 | 急停与未知驱动状态为锁存故障；清除前验证停机和故障源消失 |
| `Config.load/commit` | 版本化配置 -> 验证后的只读快照/错误 | 范围校验、CRC/完整性、原子更新；运行中配置冻结，下一任务生效 |

内部算法统一 mg 和单调 ms；显示或协议边界负责单位转换。HX711 原始码值不等于质量；校准比例、零点与温漂补偿的形式在实测后确定。不得在未确认量程前固定最大 mg 常数。

称重快照的首版 C 字段和可用性检查契约由 `tasks/TASK-WEIGHT-003.md` 冻结：0~8 通道、`int32_t` 原始计数、`int64_t` mg、`uint64_t` 单调 ms、非零校准版本、有效/稳定/故障标志；样本时效由调用者提供参数。该契约不决定校准、滤波或并发发布实现。

N16R8 的 PSRAM 只通过显式 `heap_caps_malloc(..., MALLOC_CAP_SPIRAM)` 给大块、非实时缓存使用。控制状态、队列、ISR 数据、DMA 缓冲和任务栈默认保留内部 RAM；不得因外部 RAM 容量充足而隐式迁移实时路径。

## 并发与所有权

初版建议一个有界周期的 `control task` 独占任务状态机，一个 `weight acquisition task` 负责九路采样，一个低优先级 `event/storage task` 消费有界事件队列；ESP-IDF 自带网络任务/事件循环只做适配。`Safety Supervisor` 可由控制任务周期检查加硬件急停/看门狗路径实现，是否需要独立任务以测得的最坏响应时间决定，不为模块数量额外创建任务。

- 命令队列只传定长复制的命令 ID/数据或明确所有权对象；满队列拒绝新任务并返回可观察错误。取消/急停另有有界高优先级通路，不能被普通命令队列淹没。
- 称重快照由采集任务发布，控制任务读取一致副本；短时互斥或双缓冲的最终实现以测量为准。不能在持锁状态下做 I2C、日志或网络调用。
- PCA9685 的 I2C 总线访问由执行器服务串行化；如果共用 I2C，需定义所有者、超时与总线恢复。紧急关断首先动作于经验证的独立硬件关断路径，不等待 I2C 互斥锁、命令队列或网络回调，再尝试将 PCA9685 寄存器置零。任务优先级、栈、周期、队列深度、看门狗时限均 TBD，以 Phase 1 时序预算和后续实测确定。
- ISR 只采集时间/标志并通知任务；复杂校准、日志、网络和 PWM 策略不在 ISR 中运行。

## 启动与关停顺序

硬件默认关断 -> 读取并校验配置 -> 初始化总线/驱动且写全关 -> 验证执行器可控与称重有效 -> 才允许清除软件禁止启动标志。任一步失败保持关断并报告故障。正常关机、OTA 和重启前先取消任务、等待有界停机确认；复位/掉电时由硬件默认关断承担最后防线。网络连接在安全初始化之后启动。
