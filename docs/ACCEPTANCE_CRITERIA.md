# 验收标准

## 架构与安全门槛

- [ ] 独立网页/后台/数据库/设备协议可在开发电脑启动，局域网另一终端可访问；实现不依赖客户服务器账号、源码、数据库或既有 API。
- [ ] 客户交付包包含锁定依赖、启动配置、迁移、备份恢复、回滚和验收步骤；可在隔离目录/进程/数据目录部署，不覆盖其他业务资料，根路径/子路径和指定端口均有验证。
- [ ] 需求、硬件、软件、控制、状态、错误、配置、通信和测试文档均有版本并可追溯到任务/ADR。
- [ ] 实物 MCU、Flash、PSRAM、ESP-IDF、分区、引脚和功率级已核验；`TBD` 项有关闭证据或明确阻断结论。
- [ ] 上电、复位、看门狗、掉电、I2C/PCA9685 故障、OTA 中断、急停时，泵和气路保持关闭或在规定响应时间内关闭；该项必须有负载端实测 `[HW REQUIRED]` 证据。
- [ ] 任意时刻最多一个源泵输出非零，气路与泵互斥；网络/日志/存储不能直接控制输出或阻塞控制路径。
- [ ] 配置/校准缺失、损坏、过期或越界时拒绝启动；运行中使用不可变配置快照，更新原子且可恢复。

## 驱动与计量

- [ ] 九路 HX711 有明确采样、时间戳、标定、过期、稳定和断线语义；PCA9685 频率、地址、输出极性和寄存器回读经过台架验证，负载端关闭另有独立测量证据。
- [ ] 每路源秤的起止稳定质量、中央秤批次起止稳定质量、噪声/尾流/残液预算均有原始数据和校准版本。
- [ ] 规定目标质量、容差、量程、节拍、重复性和环境范围已由产品冻结；所有声称的精度只在这些工况内有效。
- [ ] 快加/慢加/精加/提前停泵/稳定/点动/最终核验及每个超时和故障出口通过测试；首版不依赖机器学习。

## 可靠性与协议

- [ ] 取消、重启、队列满、重复/迟到/未授权命令、网络断开和任务恢复符合协议；自动任务不因网络断开而改变控制结果，调试会话断线按设备租约停止输出。
- [ ] 浏览器操作经过后台、设备接受、执行和完成回执闭环；页面不把 HTTP 接收/入队显示成物理执行完成，设备实际生效版本/值可追溯。
- [ ] 参数显示偏好、调试临时值、自动任务快照、显式持久化保存和停机维护参数的生效时机均有测试证据。
- [ ] 故障码、状态转移、任务结果和配置/校准版本可关联；事件丢弃和资源不足可观察，不以静默成功替代。
- [ ] 长稳、边界液体、振动、滴液、线束/电气异常和制造流程通过适用项目。

## 放行规则

所有适用项必须有 `[PASS]` 证据；未完成硬件项标记 `[HW REQUIRED]` 不能作为最终接受。任何 P0/P1 安全或计量缺陷、未授权架构变化、未关闭阻断 TBD 均为 `CHANGES REQUIRED`。评审输出只能是 `ACCEPTED` 或 `CHANGES REQUIRED`，后者必须指出文件、函数/接口（如适用）、问题、原因、预期修改和验收方法。
