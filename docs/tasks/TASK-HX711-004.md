# TASK-HX711-004：单路 HX711 有界驱动接口

## Gate

实现驱动接口和主机替身，不宣称实物通过。九个 HX711 尚未到货，实际 GPIO、电平、SPS、增益和转换时序必须标记 `[HW REQUIRED]`。

## Objective

定义单路 HX711 的初始化、就绪等待、24 位有符号读取、超时、断线和停止接口，为九路 Weight Service 提供窄接口。驱动不能做校准、滤波、网络或控制决策。

## Safety and timing

每次等待和时钟脉冲都有上限；超时立即返回故障，不能无限轮询。SCK 高电平时间、DOUT 电平、10/80 SPS、供电和 GPIO 只能从实物/数据手册配置读取，不能写猜测值。驱动代码不使用 PSRAM，采样缓冲在内部 RAM。

## Allowed files

仅允许新增 `components/weight/` 驱动文件、主机替身/逻辑测试和 `docs/agent_reports/TASK-HX711-004.md`。禁止接入控制器、PCA9685、HTTP 或服务器；不刷机。报告结尾 `READY FOR ARCHITECT REVIEW`。
