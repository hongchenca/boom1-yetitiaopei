# 硬件架构与待确认参数

## 已知连接与设计约束

- 用户确认 ESP32-S3-WROOM-1-N16R8 为主控；九个 HX711 接九组称重传感器。每路 DOUT/SCK 连接、电平、上电行为和采样率须由原理图/实物确认。
- PCA9685 经 I2C 接 ESP32-S3，16 路 12 位 PWM，CH0~7 暂配泵，CH8 暂配气路，CH9~15 保留。所有通道共用一个 PWM 频率；驱动逻辑不能为各泵设置独立频率。40~1000 Hz 是当前模块标称范围，不是泵和 MOSFET 的已验证工作频率。
- PCA9685 输出只接 MOSFET 驱动输入，严禁以其输出直接供电电机。气路执行器实际类型和功率级 TBD。
- 关断电路必须保证主控 GPIO 高阻、复位、启动、I2C 故障、PCA9685 残留输出、异常重启期间泵和气路均不会被误激活。必须提供不依赖 I2C 写入成功的默认关断路径；可选拓扑包括受控使能或电源隔离，具体实现和诊断覆盖范围在 Phase 1 冻结。若现有板卡无法实现，必须明确硬件返工，不得仅靠固件补救。
- 急停、熔断/过流、反灌与感性负载抑制、供电分区、接地及 EMC 方案必须依据电流与线缆实测设计，现阶段不指定器件值。

## ESP32-S3-WROOM-1-N16R8 GPIO 接线规划

以下为模块 GPIO 编号，不是开发板排针位置。以目前 UART0 下载/日志和九个 HX711 各用独立 DOUT/SCK 为前提；接线前必须核对实际开发板原理图或丝印，确认这些 GPIO 确实引出且未被板载外设占用。当前 PCA9685 空载台架只接本表前 3 行，不接泵、MOSFET、气路或 HX711。地址焊盘 A0~A5 保持默认低电平时，预期 7 位地址为 `0x40`，仍须以模块实物和 I2C 应答核对。

| 功能 | ESP32-S3 GPIO | 接线/电气约束 |
| --- | --- | --- |
| PCA9685 SDA | GPIO8 | 接 SDA；总线上拉只能到 3.3 V |
| PCA9685 SCL | GPIO9 | 接 SCL；总线上拉只能到 3.3 V |
| PCA9685 OE | GPIO10 | OE 高电平禁止输出；OE 外接上拉到 3.3 V，使 MCU 复位/高阻时默认禁止；初始化全部 FULL_OFF 后才允许拉低 |
| 功率级总使能 | GPIO11 | 未来接口定义为高电平允许使能，外部下拉确保复位默认断开；具体隔离电路待设计，当前不连接 |
| 急停健康状态输入 | GPIO12 | 未来定义高电平为健康、低电平为停机/断线；急停必须同时直接切断功率使能，不能仅依赖此 GPIO，当前不连接 |
| 功率级故障输入 | GPIO13 | 未来接功率级故障反馈；有效极性和电平待实际模块确认，当前不连接 |
| HX711 Scale 0 DOUT / SCK | GPIO1 / GPIO2 | 独立一组；当前不连接 |
| HX711 Scale 1 DOUT / SCK | GPIO4 / GPIO5 | 独立一组；当前不连接 |
| HX711 Scale 2 DOUT / SCK | GPIO6 / GPIO7 | 独立一组；当前不连接 |
| HX711 Scale 3 DOUT / SCK | GPIO14 / GPIO15 | 独立一组；当前不连接 |
| HX711 Scale 4 DOUT / SCK | GPIO16 / GPIO17 | 独立一组；当前不连接 |
| HX711 Scale 5 DOUT / SCK | GPIO18 / GPIO21 | 独立一组；当前不连接 |
| HX711 Scale 6 DOUT / SCK | GPIO39 / GPIO38 | 独立一组；GPIO39 为外部 JTAG 引脚 |
| HX711 Scale 7 DOUT / SCK | GPIO41 / GPIO40 | 独立一组；GPIO40/41 为外部 JTAG 引脚 |
| HX711 Scale 8 DOUT / SCK | GPIO42 / GPIO47 | 中央容器；GPIO42 为外部 JTAG 引脚 |

保留 GPIO0/3/45/46 启动配置脚、GPIO19/20 原生 USB、GPIO26~37 Flash/Octal PSRAM、GPIO43/44 UART0；GPIO48 暂不分配，部分开发板用作板载 RGB LED。GPIO39~42 分配给 HX711 后，不能同时使用这些引脚的外部 JTAG；当前 UART 下载/日志不受影响。若开发板未引出 GPIO47、占用表内任何脚位，或未来需要外部 JTAG，须在接 HX711 前重排引脚，不可直接复用。其他门禁、漏液、液位等未定传感器未占脚，需另行确定接口；急停/功率切断不应交给 I2C 扩展器。

PCA9685 台架供电：VCC 接 3.3 V，GND 与 ESP32 共地，SDA/SCL 的板载或外接上拉接 3.3 V；V+ 不接，所有输出不接功率负载。OE 接 GPIO10 前先确认该模块没有将 OE 硬接地或接到其他驱动，且外部上拉确实使其上电为高；不可让 GPIO10 与固定电源/地短接。GPIO10 只控制 OE，不替代 `ADR-0003` 要求的独立功率关断。HX711 后续接入前核对模块 DOUT 电平；5 V DOUT 不得直接接 ESP32-S3 GPIO。引脚可用性依据 Espressif《ESP32-S3-WROOM-1 & WROOM-1U Datasheet》v1.8 §3.2（N16R8 的 IO47 可用，IO35~37 被 Octal PSRAM 占用）、ESP-IDF 5.4.2 ESP32-S3 GPIO/JTAG 文档和当前 UART 配置；实物载板占用仍待核验。

## 已发现的配置冲突

原 `sdkconfig` 为 ESP32-S3、2 MB Flash、关闭 PSRAM、单应用分区。依据用户确认的 N16R8 料号，现已将 Flash 配为 16 MB、PSRAM 配为 Octal/80 MHz/启动自检/显式 `MALLOC_CAP_SPIRAM` 分配，控制任务栈不允许放在外部 RAM。保留原 DIO/80 MHz Flash 时序与单应用分区；OTA 布局另行设计。`sdkconfig.old` 指向 ESP32 目标，不能用于推断当前板卡。板上仍须读取实际容量并验证启动稳定性，不能仅凭构建配置宣称实物通过。
