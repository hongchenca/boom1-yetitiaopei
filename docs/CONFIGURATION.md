# 配置、校准与持久化

## 配置分层

1. **板级只读**：硬件版本、通道映射、GPIO、PCA9685 地址、执行器有效极性；写入前需制造/维护权限，映射变更要求 ADR。
2. **计量校准**：每路零点、比例、方向、温漂/线性校正版本、校准时间和操作者；校准不完整时该通道不可用于定量。
3. **控制参数**：阶段占空比、预停点、超调补偿、速度估计限制、稳定窗口、点动脉冲、超时和质量守恒带；全有单位、范围和版本。
4. **产品/通信参数**：任务超时、权限、重试、事件保留、网络/OTA 地址与证书引用；凭据不能写入日志或普通配置导出。

## 网页与运行环境配置

独立网页/后台的监听地址、端口、`APP_BASE_PATH`、服务 URL、SQLite/日志目录、模拟开关、登录配置、设备凭据和连接超时由运行环境配置提供。开发阶段默认在电脑上启动，局域网调试时监听实际网卡地址；客户部署使用独立账号、目录、端口和数据目录，不读取或覆盖其他业务资料。浏览器使用相对 API/资源地址，根路径和子路径部署都必须验证。

## 记录格式契约

配置记录包含格式版本、schema 版本、单调/墙钟生成时间、硬件兼容范围、内容长度、CRC/完整性校验和提交来源。更新采用双槽或等价原子策略：写入非活动槽、校验、标记有效、再切换；掉电只能选择最近一个完整槽。启动检测到两槽无效时保持全关并进入 `CFG` 故障。

运行中的自动任务捕获不可变配置快照；新的配方、目标量和控制参数只对下一次自动任务生效。调试会话中的临时速度/点动等参数经设备校验后只写入会话 RAM，不按滑块刷新写入 NVS；需要持久化时必须显式保存、回执确认并原子更新。禁止一半任务读取旧参数、一半读取新参数。配置迁移必须保留旧版本解释器或明确拒绝，并有回滚记录。

## 范围校验原则

- 目标质量、容差、占空比、频率、超时、点动次数、窗口和队列容量先检查有限性、单位和上下界，再检查跨字段关系（如容差小于最大剂量、停止阈值不为负、总超时覆盖阶段上限）。
- 硬件标定量程来自实际 Load Cell/HX711 数据，未确认的容量保持 `TBD`，不得用占位值启用泵。
- GPIO/通道映射必须唯一；保留通道禁止被配方引用；PCA9685 频率变更必须重新验证所有负载。

## 默认与安全

无配置、配置损坏、版本不兼容、校准过期或超出范围时，默认泵/气路全关并拒绝任务。恢复出厂不代表恢复危险输出；恢复后仍需重新验证硬件互锁和校准。敏感项只保存引用/加密形式，诊断打印只输出版本、哈希和状态。
