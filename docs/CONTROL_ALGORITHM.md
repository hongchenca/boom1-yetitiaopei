# 定量控制算法

## 变量与数据时序

内部统一使用 `mg`、`ms`、`duty_percent`。每路先建立空载/起始稳定窗口，运行中使用带单调时间戳的重量快照。源通道当前可交付量估计为 `source_start_stable - source_current_filtered`；最终剂量只使用停泵后稳定窗口的 `source_start_stable - source_end_stable`。中央容器的 `main_gain` 同理由批次起止稳定窗口计算。

重量滤波必须同时输出有效性、稳定性、窗口跨度和估计噪声。控制器禁止因为单个跳变或未稳定样本改变状态。滤波器类型、窗口长度、稳定阈值和最长样本年龄都是配置参数，并须在台架数据上验证。

## 首版单通道控制

每个配方步骤独占一个源通道，状态机见 `STATE_MACHINE.md`。每个阶段由目标剩余量、目标容差、最短/最长驻留时间、传感器有效性和任务取消共同约束。控制输出由执行器服务产生，控制器只提出占空比目标。

1. **FAST_FILL**：以保守占空比快速接近目标，建立该泵的初始流量估计。
2. **SLOW_FILL**：进入预停点后降低占空比，按稳定窗口更新质量速度估计。
3. **FINE_FILL**：低占空比运行，目标是减少单次惯性造成的超调。
4. **STOPPING**：输出全关；记录关断时刻并等待泵和管路的迟滞消退。任何关断写入失败均转 `ERROR`/安全关断。
5. **SETTLING**：等待源秤和中央秤在规定窗口内稳定；等待超时不直接当成功。
6. **JOG_FILL**：若稳定结果低于目标且在允许点动次数/单次质量/总时限内，以短脉冲补加；每次脉冲后必须重新停止并稳定。
7. **VERIFY**：检查源通道最终剂量、中央增重、传感器健康、允许的质量守恒带和配置版本，生成可追溯结果。

## 超调与流量估计

预停质量由可配置的 `overshoot_compensation_mg` 和动态流量预测组成：

`stop_threshold = target_mg - overshoot_compensation_mg - predicted_tail_mg`

其中 `predicted_tail_mg` 只能使用最近稳定样本间的有界质量速度、已知关断延迟和上限；样本不足、速度异常或模型越界时退回保守固定值并记录降级原因。估计不得为负，也不得让停止阈值越过阶段边界。首版不使用机器学习。

流量估计只用于提前关断和阶段选择，不替代最终稳定称重。每次新泵、液体、管路或维护后应通过校准任务更新参数；运行中估计仅在单调、有效、时间间隔满足下限时更新。

## 点动与误差决策

稳定结果 `dose_mg` 与目标比较：

- `abs(error) <= tolerance_mg`：进入 `VERIFY`。
- `error > tolerance_mg`：若未超过点动上限、时间上限和源库存上限，进入 `JOG_FILL`；否则判为 `ERROR` 或“质量警告”，取决于已冻结的产品策略，默认阻止任务完成。
- `error < -tolerance_mg`：过量不可通过倒吸假装修正；立即停机并报告过量故障，是否允许人工回收另列操作流程。

## 交叉验证

批次完成时比较 `sum(source_loss)` 与 `main_gain`。比较必须使用相互对应的稳定窗口，并带管路滞留、飞行液体、滴液和秤噪声预算。质量差值至少分为：可解释滞留带、警告带、故障带，三个边界均为配置且由实测标定；没有冻结标定时只能记录差值，不能宣称质量守恒通过。

## 安全与时序约束

- 任何阶段发现秤失效、数据过期、I2C/PCA9685 写失败、任务/阶段超时、急停、配置失效、主控看门狗或安全互锁断开，先执行有界 `stop_all`，再锁存错误。
- 网络、日志、NVS 写入不能位于控制周期的阻塞路径；结果事件用有界队列异步写入。队列满时保留安全状态和故障计数，不能延长泵运行。
- 控制周期、采样周期、I2C 更新最坏时延、停泵尾流、稳定窗口和看门狗余量必须在 Phase 1 时序预算中给出，现阶段均为 TBD。
