# ADR-0005：实时滤波与分阶段定量控制

- 状态：软件策略已采纳；硬件参数和标定数据待验证
- 日期：2026-09-26

## 决策

本地控制闭环不依赖网络、HTTP、日志或 Flash 写入。控制任务以 20 ms 有界 tick 运行，Weight Service 按 HX711 实际转换速率发布快照；控制器可以重复消费最近快照，但不得把重复快照当作新样本。

每路重量使用“原始 24 位范围检查 -> 校准整数 mg -> median-of-3 -> 定点 EMA -> 固定稳定窗口”的管线。滤波器输出有效性、样本年龄、噪声和斜率；样本过期、故障或校准无效时禁止阶段推进。所有参数（alpha、窗口数、噪声带、斜率带、最大年龄）版本化配置，必须由实测标定填写。

控制阶段固定为 `FAST_FILL`、`SLOW_FILL`、`FINE_FILL`、`STOPPING`、`SETTLING`、`JOG_FILL`、`VERIFY`。单泵互斥、气路互斥、点动次数/质量/时间有上限；任何传感器、I2C、配置、互锁或超时故障先停机再锁存。过量不允许用倒吸假设修正。

## 后果

控制结果可在服务器断开时继续运行，网络和存储不会拖长泵运行。滤波引入确定的样本延迟，必须把延迟纳入预停和尾流预算。没有 HX711、泵和液路实测数据时，系统可以完成仿真和无负载驱动测试，但不能宣称实际剂量精度或节拍。

## 验证

主机测试覆盖滤波边界、时间戳、断线、跳变、稳定/不稳定、整数溢出和所有状态转移；台架测试覆盖真实采样率、噪声、尾流和停泵响应；负载端测试单独验证独立关断。
