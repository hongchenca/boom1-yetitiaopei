# ADR-0002：单泵串行与控制所有权

- 状态：已采纳为首版边界
- 日期：2026-09-24

## 决策

首版同一时刻最多一台源泵工作，气路与泵互斥。`Dosing Controller` 独占任务状态，`Actuator Service` 独占 PCA9685/硬件输出，`Weight Service` 独占 HX711 采集；网络、日志和 OTA 只能通过服务契约间接影响执行。

## 原因

源秤减重和中央秤增重需要可归因、可对齐的质量变化；在液路、尾流、振动和采样延迟尚未测量前并行泵会扩大误差和故障归因范围。单泵串行能先验证安全与计量闭环。

## 后果

首版吞吐受限；若产品必须并行，需基于实测误差预算、安全互锁和调度模型提出新 ADR，不得在实现中顺手放开并行。

## 验证

状态机和执行器台架必须证明并行请求被拒绝/串行化、气路互斥、异常时全部关断，交叉验证记录能按步骤归因。
