# ADR-0006：网页后台、本地联调与客户部署的边界

- 状态：2026-09-30 网页/网络联调子集已实现，硬件及生产交付待完成
- 日期：2026-09-26；修订：2026-09-30

## 2026-09-30 阶段决策（替代下文早期技术栈建议）

当前采用本工程 web_server/ 下的 Node.js 24.14.x 标准库 + SQLite + 静态 HTML/CSS/JS，暂无第三方依赖，不采用兄弟目录中的 FastAPI/Vue 建议，也不修改 fwq 或客户文件。客户运行时需提供经验证的 Node；SSE/设备上行/命令回执的协议和独立交付边界不变。

main/web_client.c 是互斥 WEB_CLIENT 网络入口，只允许 ping/上报周期；硬件控制仍须由未来 Command/Actuator Service 负责。模拟器五秒归零仅供 UI 演示。当前无完整角色、标定、配方/自动配液、schema 迁移或最终生产部署包；实施状态见 WEB_SERVER_PLAN.md 与任务报告。

## 决策

完整网页和后台先运行在用户电脑，通过局域网调试 ESP32，最终以独立应用包交给客户部署。客户不提供服务器管理权限，开发不依赖其其他业务资料或内部 API。详细方案见 `../WEB_SERVER_PLAN.md`。

建议 Vue 3 + TypeScript 页面、FastAPI 后台和专用 SQLite，新增到 `E:\111111111\yeti\fwq\yetitiaopei_app\`，保留其他文件。浏览器通过同源 HTTP/SSE 与后台交互；设备主动上传遥测/事件并长轮询命令，局域网和客户部署使用同一协议。ESP32 完整内置页面不是主控制台的前置依赖。

所有设备动作进入 Command Service，执行身份、权限、schema、范围、过期、幂等和队列检查。实时调试采用有期限、有限输出和单操作者的会话；自动配液继续使用不可变配置快照，新参数下次任务生效。调试失联由设备期限触发停机，自动任务按本地状态机继续。网页和后台不能直接操作 GPIO/I2C。

客户部署采用独立目录/进程/数据目录和可配置端口；提供启动、代理、备份、迁移和回滚资料，由客户运维执行。HTTP/TLS、重试、队列和存储均有界。

## 对旧决策的替代与部署输入

原“等待既有服务器入口/API，再开发适配器”的假设已被用户明确的独立交付方式替代。页面、后台、模拟器和局域网开发可以开始；客户 OS/运行环境、端口/域名/代理、数据路径、设备网络可达性和离线安装要求仅用于最终打包和部署适配，不要求客户提供服务器账号或其他业务源码。

## 验证

使用真实启动的本机后台和模拟设备检查页面、回执、生效值及曲线；局域网验证跨终端访问和实机数据。测试覆盖未授权、重复/过期/乱序、取消抢占、调试租约到期、后台/设备重启、配置版本冲突和事件去重。交付包在干净环境演练部署、子路径、备份与回滚；真实执行器按硬件验收门槛单独验证。
