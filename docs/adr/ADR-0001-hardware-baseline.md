# ADR-0001：硬件基线与未确认参数策略

- 状态：容量配置策略已采纳，实物核验等待 `TASK-HW-001` 关闭
- 日期：2026-09-24

## 背景

用户确认 ESP32-S3-WROOM-1-N16R8、九路 HX711、PCA9685/MOSFET/八泵加一路气路；仓库原 `sdkconfig` 却是 ESP32-S3、2 MB Flash、关闭 PSRAM、单应用分区，`sdkconfig.old` 甚至是 ESP32 目标。

## 决策

用户确认料号后，先将 Flash/PSRAM 配置对齐 N16R8，并在板上验证真实容量与启动；GPIO、供电、量程、PWM 频率和关断拓扑在资料/测量前仍标记 `TBD`。Phase 1 继续完成板卡、原理图与数据手册证据，不得为推进代码而猜测其他硬件参数。

## 影响

设计可以继续定义接口和安全不变量，但不能声称板上 Flash/PSRAM、计量精度或负载输出已验证。当前明确使用显式 PSRAM 分配、内部控制任务栈；OTA 分区与 DMA 缓冲的具体策略仍待定。

## 验证

读取芯片/模块身份、构建配置与分区，检查所有启动/复位/功率使能路径，并把来源写入硬件基线记录。
