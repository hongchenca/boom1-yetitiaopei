# ADR-0004：ESP32-S3 GPIO 分配与外部 JTAG 取舍

- 状态：接线规划已定，开发板引脚引出与板载占用待实物核验
- 日期：2026-09-24

## 背景

ESP32-S3-WROOM-1-N16R8 需连接 PCA9685、九个 HX711，以及未来独立功率使能和安全反馈。当前工程使用 UART0 控制台，不能占用下载/日志接口；16 MB Flash 与 Octal PSRAM 占用的引脚也不能当通用 GPIO。用户当前仅持有空载 PCA9685，需先完成低风险 I2C/PWM 台架验证。

## 决策

GPIO8/9 分别作为 I2C SDA/SCL，GPIO10 控制 PCA9685 OE。GPIO11 留给默认断开的独立功率总使能，GPIO12 留给急停健康状态回读，GPIO13 留给功率级故障反馈。九个 HX711 各保留独立 DOUT/SCK，引脚逐路分配见 `HARDWARE_ARCHITECTURE.md`。GPIO39~42 因引脚预算分配给 HX711，放弃这些脚位上的外部 JTAG；GPIO19/20 原生 USB 与 GPIO43/44 UART0 保留。GPIO48 不预分配，以便核对开发板板载功能。

## 后果

PCA9685 可先只接 GPIO8/9/10 和 3.3 V/GND 测试；此时不连接任何功率负载。HX711 接线前必须确认开发板是否引出所有规划 GPIO；若板载器件占用或必须使用外部 JTAG，则先重排分配。独立 SCK 便于逐路采样与故障隔离，但剩余 GPIO 很少；新增慢速非安全输入需要单独规划。急停必须直接作用于硬件功率关断路径，GPIO12 仅用于状态回读；仅有 GPIO10/OE 无法满足独立关断要求。
