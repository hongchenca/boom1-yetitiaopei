# ADR-0003：独立于 I2C 的默认关断路径

- 状态：已采纳为安全要求；实现拓扑待硬件核验
- 日期：2026-09-24

## 背景

PCA9685 可能在 MCU 复位或 I2C 故障期间保持既有输出。仅通过 I2C 写零无法保证上电、复位、总线卡死和看门狗路径下的泵端断电。

## 决策

系统必须有不依赖 I2C、普通命令队列和网络的默认关断路径，覆盖所有泵与气路。上电/复位默认断开，软件紧急停机先触发该路径，再尝试清零 PCA9685。具体极性、器件和诊断方法需根据板卡实物确定；若当前板卡无法实现，阻断负载运行并提出硬件返工。

## 后果与验证

增加硬件使能/隔离设计及负载端验证要求。Phase 1 必须用示波器/电流测量证明复位、断电、I2C 卡死、PCA 输出残留和急停下的实际关断；寄存器回读不能替代负载测量。
