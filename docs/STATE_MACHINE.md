# 定量状态机

## 状态

| 状态 | 进入条件 | 允许动作 | 离开条件/保护 |
| --- | --- | --- | --- |
| `IDLE` | 上电安全初始化完成或任务结束 | 接受经过校验的任务 | 新任务 -> `PRECHECK`；安全故障 -> `ERROR` |
| `PRECHECK` | 任务已锁定配方与配置快照 | 检查九路秤、库存、互锁、执行器全关 | 通过 -> `FAST_FILL`；失败/取消 -> `ERROR`/`ABORTED` |
| `FAST_FILL` | 当前步骤允许快速段 | 保守高速 PWM | 接近预停点 -> `SLOW_FILL`；超时/故障 -> `STOPPING` 后 `ERROR` |
| `SLOW_FILL` | 快速段完成 | 降低 PWM、更新流量估计 | 接近精停点 -> `FINE_FILL`；故障 -> `STOPPING` |
| `FINE_FILL` | 进入精加段 | 低速 PWM | 预测达到 -> `STOPPING`；故障 -> `STOPPING` |
| `STOPPING` | 已发出停止请求 | 确认输出为零并记录尾流起点 | 确认 -> `SETTLING`；关断失败 -> `ERROR` |
| `SETTLING` | 泵已停且等待稳定 | 采集稳定窗口 | 稳定 -> `JOG_FILL`/`VERIFY`；超时 -> `ERROR` |
| `JOG_FILL` | 稳定结果不足且在限制内 | 执行一次有界点动 | 点动结束 -> `STOPPING`；限制/故障 -> `ERROR` |
| `VERIFY` | 步骤或批次结果已稳定 | 完成源秤/中央秤交叉验证，发布记录 | 通过且有下一步 -> 下一步骤 `FAST_FILL`；通过且无下一步 -> `DONE`；失败 -> `ERROR` |
| `DONE` | 批次所有步骤通过 | 保持全关，发布结果 | 新任务 -> `PRECHECK`；复位 -> `IDLE` |
| `ERROR` | 任何不可安全继续的故障 | 保持全关、锁存故障、保存事件 | 人工复核/安全条件满足后 -> `IDLE`；不可清除则保持 |
| `ABORTED` | 用户取消或安全路径取消 | 全关并记录部分结果 | 清理完成 -> `IDLE`；故障 -> `ERROR` |

## 不变量

1. 任意时刻最多一个源泵输出非零；气路输出与泵互斥。
2. 除 `FAST_FILL`、`SLOW_FILL`、`FINE_FILL`、`JOG_FILL` 外，输出必须为零。进入这些状态前必须有有效、未过期的称重快照。
3. `ERROR`、`ABORTED`、`DONE`、`IDLE` 均保持执行器全关；清除错误不会自动恢复原任务。
4. 每个状态都由单调截止时间、取消检查和传感器/执行器健康条件守护；禁止无限等待。
5. 状态转移、原因、配置版本和样本时间戳写入内存事件；持久化异步完成，不能改变安全转移。
6. 任务状态只能由控制器写入；网络状态、日志结果或 UI 观察不得反向写状态。

## 取消、重启和恢复

取消优先于普通阶段动作：发出停止、确认全关、记录已完成步骤和部分剂量，再进入 `ABORTED`。MCU 复位后不得自动恢复泵动作；启动时从持久化记录恢复为“未完成、需人工确认”的任务，且默认进入 `IDLE` 或 `ERROR`，由产品策略决定是否可继续称重而不自动执行。

## 状态机验收重点

测试必须覆盖每条转移及其反向/失败路径：停泵写失败、秤数据过期、中央秤不稳定、队列满、看门狗复位、重复取消、掉电后重启、点动次数耗尽和过量。任何状态都要证明泵和气路的安全输出。
