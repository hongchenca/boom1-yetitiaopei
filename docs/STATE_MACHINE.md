# 定量状态机（0.6.1）

名称对应 `components/dosing/dosing_controller.c` 的遥测状态。自动任务独占全部输出，液泵与气泵互斥；手动多泵调试不属于此状态机。

| 状态 | 动作 | 退出条件 |
| --- | --- | --- |
| `idle` | 所有输出关闭 | 显式启动新任务 |
| `precheck` | 检查本批用到的秤、版本、库存、容量与输出全停 | 稳定合格后开始第一步；不稳定有期限 |
| `route_vessel` | 只驱动舵机到配液位置 | 指令应用后等待完整 `route_ms` |
| `fast` / `slow` | 当前一个液泵按快/慢占空比工作 | 预停阈值或精加阈值到达 |
| `stopping` | 液泵与气泵关闭，保留舵机位置 | 确认电机输出为零后开始判稳；关断超时为故障 |
| `settling` | 等待停泵后的完整稳定窗口 | 不足进入补液；过量故障；合格进入清液 |
| `fine` / `jog` | 当前液泵执行有界精加脉冲 | 达到容差或脉冲硬截止后回到 `stopping` |
| `route_waste` | 液泵已停，只切舵机至废液位置 | 指令应用后等待完整 `route_ms` |
| `purge` | 限时开启气泵，监控容器变化 | 吹气期限到达，或重量变化异常 |
| `purge_settle` | 停气、等待新稳定窗口、复核单步剂量/源液/容器变化 | 合格后下一步 `route_vessel`；最后一步通过整批核验后 `done` |
| `done` | 全部输出关闭，保留最终各步剂量 | 可以显式启动新批次 |
| `error` | 全停，保留原因与已有部分结果 | 排查后显式启动新批次；驱动故障锁存须本地维护处理 |
| `aborted` | 用户取消，全停，不额外吹气 | 可以显式启动新批次 |

通用检查在每个活动节拍执行：取消、执行器故障、控制迟到、单步/整批超时、样本有效性与新鲜度、校准版本、过量和异常质量变化。

停止优先于普通输出：服务应用目标时先关旧电机，再设置舵机或新电机；保留源身份与停止代次检查。运行中的配液即使暂时停泵判稳，也不释放调试控制权。租约意外到期视为控制中断。

`dosing_start` 命令回执是接受任务，不能作为 `done`。最终成功需设备清液后稳定称重核验，网页只显示状态，不决定状态转移。重启回到待机，不恢复任务；位置与称重校准从 NVS 加载，批次结果当前不在设备持久化。

停止舵机 PWM 仅撤销控制信号，不保证机械回到某个位置。没有机械到位反馈，因此 `route_ms` 必须按实际舵机负载测量并留余量。
