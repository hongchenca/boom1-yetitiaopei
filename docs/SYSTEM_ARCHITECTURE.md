# 总体系统方案

## 信号与能量路径

```text
8 个原液容器 -> 8 组 Load Cell/HX711 -> Weight Service ----+
中央容器   -> 1 组 Load Cell/HX711 -> Weight Service ----+----> Dosing Controller
                                                          |          |
配方/本地命令 -> Command Service -> 校验/排队 -------------+          v
网络适配器 ----> Command Service                       Actuator Service
                                                               |
                                               I2C -> PCA9685 -> MOSFET -> 泵/气路
```

另有独立安全关断路径：上电/复位期间负载默认断电；软件失效或主控复位时不依赖 PCA9685 的旧 PWM 状态保持关闭。具体电路与验证见 `HARDWARE_ARCHITECTURE.md`。

## 控制所有权

- `Dosing Controller` 是任务状态与剂量决策的唯一写入者；一次只执行一个配方步骤。所有入口经 `Command Service` 进行鉴权、去重、参数校验和串行化。
- `Actuator Service` 是 PCA9685 输出与硬件使能的唯一软件写入者；它只接受受约束的执行命令，失败时尝试全部关闭并将故障上报。网络、测试 UI 和 OTA 均不得直接写 PWM。
- `Weight Service` 独占 HX711 采集及校准数据，向控制器提供带单调时间戳、有效性、稳定性和校准版本的快照；过期/失效值不能当作新样本使用。
- `Safety Supervisor` 监测看门狗、驱动/传感器故障、急停和超时，能向执行服务发出高优先级关断请求；任何故障锁存的释放必须显式复核。
- 网络和存储模块只交换有界消息或只读快照，不参与硬件闭环。网络离线时已开始的自动任务继续，手动调试会话按设备租约到期停止输出；远程提交暂不可用。

## 质量守恒与批次边界

每步骤的 `source_loss = source_start_stable - source_end_stable`；过程中的 `source_start - current` 可用于提前停泵，但不是最终结算值。整批 `main_gain = main_end_stable - main_start_stable`。中央秤在批次前后完成稳定采样；若有逐步核验需求，每步也须等待稳定并记录时间窗口。交叉验证允许有明确标定的管路滞留和损耗带，不能要求数值瞬时相等。

首版对八通道串行配料，任意时刻至多一台泵工作。中央秤异常是安全异常还是质量警告由经验证的故障策略决定；在策略冻结前按阻止新步骤和关闭执行机构处理。气路动作与计量步骤互斥，默认不在剂量闭环中使用。

## 开发阶段与放行门

| 阶段 | 交付物 | 进入下一阶段的门槛 |
| --- | --- | --- |
| Phase 1：需求、硬件与安全基线 | 原理图/接线证据、TBD 关闭计划、失效安全原型、接口与测试计划冻结 | 板卡/供电/关断路径可核验；关键硬件未知项已关闭；设计评审通过 |
| Phase 2：驱动与计量基础 | PCA9685/HX711 驱动、九路采集、校准与故障注入测试 | 单元/台架测试通过；采样时序与全关断实测 |
| Phase 3：本地定量闭环 | 单泵串行状态机、流量估计、超调补偿、点动、验证 | 按冻结的精度/节拍目标完成跨液体与边界测试 |
| Phase 4：配方、持久化与可观测性 | 原子配置、任务记录、恢复策略、操作接口 | 断电/重启/配置损坏行为与审计可验证 |
| Phase 5：网络与 OTA | 协议适配、身份认证、离线策略、OTA 回滚 | 网络异常不影响运行中的自动任务，调试租约失效按约停止；升级安全门槛通过 |
| Phase 6：系统验收 | 长时运行、故障矩阵、制造与现场验证 | `ACCEPTANCE_CRITERIA.md` 全部适用项有可追溯证据 |

阶段可以迭代，但不得跳过失效安全、量程和电气验证去启动负载。Phase 1 的任务拆解见 `PHASE_1_PLAN.md`。

## 关键架构决策

首版单泵串行、控制器独占状态、执行器独占输出、硬件默认关断与数据版本化记录在 `adr/`。任何改变并发泵数量、计量主依据、共享 PWM 时基、安全关断路径或网络控制边界的提案，先更新 ADR 和测试/验收，再交 Coding Agent 实施。
